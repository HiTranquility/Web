Forwarded to a plain HTML page

Look at the address bar It still says /forward?target=html. You are reading /demo/forward_target.html, and the browser has no idea.

This file is ordinary static HTML — no JSP, no EL, no Java. That is why it cannot show you the request attribute the servlet set: a plain .html file is served as bytes, nothing evaluates anything inside it. Forward to a .jsp when the target needs to read what the servlet put in the request.
