1. YÊU CẦU MÔI TRƯỜNG (PREREQUISITES)
--------------------------------------------------------------------------------
- Hệ điều hành : Windows 10 / 11
- Java JDK     : Phiên bản 17 (hoặc 11+ trở lên)
- Cơ sở dữ liệu: MySQL Server 8.0 (cổng 3306 mặc định)
- Trình điều khiển: Windows PowerShell (mặc định có sẵn trên Windows)

--------------------------------------------------------------------------------
2. HƯỚNG DẪN CÀI ĐẶT CƠ SỞ DỮ LIỆU (DATABASE SETUP)
--------------------------------------------------------------------------------
Cách 1 (Khuyên dùng - Cài đặt tự động 1 lệnh duy nhất):
  Mở PowerShell tại thư mục dự án và chạy:
    powershell -ExecutionPolicy Bypass -File scripts\setup-db.ps1
  (Script sẽ tự khởi tạo database, nạp 25 bảng CSDL, nạp dữ liệu mẫu và sinh file db.properties)

Cách 2 (Thủ công qua MySQL Workbench / phpMyAdmin / CLI):
  - Tạo database:
      CREATE DATABASE IF NOT EXISTS doan_webdoctruyen CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
  - Import theo thứ tự: database/schema.sql và database/sample_data.sql
  - Chép file `src/main/resources/db.properties.example` thành `src/main/resources/db.properties`
    và điền tài khoản/mật khẩu MySQL máy tính của bạn.

--------------------------------------------------------------------------------
3. HƯỚNG DẪN KHỞI CHẠY ỨNG DỤNG WEB (RUN DEV SERVER)
--------------------------------------------------------------------------------
Dự án đã tích hợp sẵn Apache Tomcat 9 nhúng trong thư mục `.libs/`. Không cần cài
đặt máy chủ Tomcat bên ngoài hay cấu hình phức tạp:

Bước 1: Mở cửa sổ PowerShell tại thư mục dự án.
Bước 2: Thực thi lệnh:
          .\scripts\run.ps1
        (Mặc định chạy tại cổng 8080. Đổi cổng nếu muốn: .\scripts\run.ps1 -Port 9090)

Bước 3: Mở trình duyệt web (Google Chrome, Microsoft Edge) và truy cập:
          http://localhost:8080/
